Python Interactive Quiz

A command-line quiz application developed in Python.

Features

- Create and store quiz questions
- Randomize questions and answers
- Check user answers
- Calculate final scores
- Save game results
- View previous quiz results
- Preserve history between sessions

Technologies

- Python 3
- JSON
- Random
- OS
- Datetime

Project Structure

- "main.py" — Main application
- "questions.json" — Question database
- "resultats.json" — Quiz history

How to Run

python main.py
